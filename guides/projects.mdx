---
title: "Projects"
description: "Group a site's saved URLs, audits and monitors, and view one site at a time."
---

A project is one site's worth of work. It holds that site's saved URLs, its
audits and its monitors together, so a dashboard covering several sites can be
narrowed to the one you are actually looking at.

Free accounts get one project. Pro is unlimited.

## Scoping the dashboard

The switcher at the top of the sidebar sets the scope, and it applies
everywhere — Overview, Saved URLs, Audits and Monitors all show only what
belongs to the selected project.

The choice follows you between pages and is remembered between visits. It is
stored in your browser, not on your account, so two people sharing an account
can look at different projects at the same time.

| Scope | Shows |
| :--- | :--- |
| **All projects** | Everything on the account |
| A project | Only what is filed in that project |
| **Unfiled** | Everything filed in no project |

## Unfiled

Nothing is put into a project automatically, and there is no default project.
Anything created before you had projects — or created while the scope was **All
projects** — is unfiled, and reachable under **Unfiled**.

New work inherits the scope you are in. Save a URL while a project is selected
and it is filed there; save one under **All projects** and it stays unfiled.

<Note>
  The count beside each project is everything it holds, not just its saved URLs.
  A project with no saved URLs but six audits reads as six.
</Note>

## Moving things between projects

A saved URL can be moved at any time from the project column on the
[Saved URLs](https://metamanager.dev/saved) page.

Audits and monitors are filed when they are created and stay where they were
put — an audit is a record of a crawl that already happened, and refiling it
would change history rather than correct it.

## Deleting a project

Deleting a project keeps everything in it. Its saved URLs, audits and monitors
are moved to **Unfiled**; only the grouping is removed.

The confirmation tells you exactly what will be moved before you agree to it.
